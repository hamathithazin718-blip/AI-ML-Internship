## 🏃‍♂️ How to Set Up and Run Locally

### Prerequisites
Ensure you execute within an isolated workspace environment such as **Anaconda Prompt** or a `uv`-sandboxed window to bypass system configuration blocks.

1. **Clone the project workspace:**
   ```bash
   git clone https://github.com/hamathithazin718-blip/AI-ML-Internship.git
   cd AI-ML-Internship
   ```

2. **Acquire necessary external dependencies:**
   ```bash
   pip install qrcode pillow
   ```
   *(Note: If utilizing managed systems, append `--break-system-packages` or execute via `uv run` to guarantee package injection)*

3. **Launch the modules independently:**
   ```bash
   python basicqrgenerator.py
   python diceroller.py
   python numberguessing.py
   ```
